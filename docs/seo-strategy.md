## 유입 실적 (2026-08-22 기준)

**견적 폼이 6개월간 만든 실제 유입은 0건이다.**

2026-02-16 ~ 2026-08-22 사이 접수된 62건은 전부 봇 스팸이었다. 폼 공개(2026-02-13) 3일
만에 스팸이 시작됐고, 그 사이 사람이 넣은 요청은 하나도 없었다. 봇 차단은 조치했으나
(아래 참조) **유입 자체가 없다는 문제는 그대로 남아 있다.** 위 표의 미완 항목 —
네이버 플레이스 등록, 자격증빙 PDF, 블로그 포스팅 — 이 유입의 선행 조건이다.

## 봇 스팸 차단 (2026-08-22)

주 고객이 공무원이라 CAPTCHA 는 이탈을 유발하므로 쓰지 않았다. 대신:

- **허니팟 필드** — `components/common/HoneypotField.tsx`. 화면 밖으로 밀어낸 `website`
  입력. 사람은 채울 수 없고 봇은 채운다. 값이 있으면 400
- **최소 작성 시간** — 폼이 뜬 뒤 제출까지 3초 미만이면 400.
  프론트가 `elapsed_ms`를 함께 보낸다
- 판정 로직: `app/utils/antispam.py`의 `spam_guard` 의존성.
  `/estimate`, `/diagnosis` 두 공개 폼에 적용

`elapsed_ms`가 아예 없는 제출은 지금은 경고 로그만 남기고 통과시킨다(캐시된 구버전
프론트를 끊지 않기 위해). **스팸이 계속되면 이 분기를 차단으로 바꿀 것.**

레이트 리밋은 넣지 않았다. 유입량이 월 10건 수준이라 과한 대응이고, 실제 문의가 생긴
뒤에 판단해도 늦지 않다.

기존 스팸 일괄 삭제: `scripts/purge-spam-estimates.sh` (미리보기가 기본, `--delete`로 실행)

```
홈           → "느티나무병원 협동조합 | 조경·수목진단 전문 (수의계약 가능)"
시공사례      → "시공사례 | 조경식재·녹지관리·수목치료 실적 | 느티나무병원"
견적문의      → "조경 수의계약 견적 요청 | 빠른 견적·실적증명 제공 | 느티나무병원"
수목진단 의뢰  → "수목 진단 의뢰 | 1종 나무병원 전문 진단 | 느티나무병원"
사업소개      → "주요 사업 | 나무병원·조경식재·녹지관리·병충해방제 | 느티나무병원"
```

### `/contract` 랜딩페이지 구성

공무원이 "조경 수의계약"을 검색했을 때 도착하는 **핵심 전환 페이지**.

```
[1] 헤더 — "조경·수목관리 수의계약"
    "견적서 즉일 발급 · 자격증빙 즉시 제공 · 실적증명 바로 확인"
[2] 수의계약 가능 서비스 목록 (카드형, 서비스별 실적 건수 + 실적 보기 링크)
[3] 보유 자격·등록 현황 (1종 나무병원 / 조경업 면허 / 산림사업 등록)
[4] 주요 발주처 (신뢰 시그널 — 시청·구청·행정복지센터 로고)
[5] 수의계약 절차 안내 (견적요청 → 현장확인 → 견적서 발급 → 계약 → 시공 → 완료보고·실적증명)
[6] 견적 요청 CTA (전화 031-752-6000 / 온라인 견적 요청)
```

## 전략 2: 공무원 어필 (들어온 공무원이 우리를 선택하게)

### 신뢰 시그널 — "증빙 즉시 확인" 구조

공무원이 업체 선정 보고서에 바로 첨부할 수 있게 자격·면허를 다운로드 가능하게 둔다.

```
✅ 1종 나무병원 (산림청 등록 제XX호)   [등록증 보기] [PDF 다운로드]
✅ 조경업 면허 (면허번호 XX-XXXX)      [면허증 보기] [PDF 다운로드]
✅ 산림사업 등록                       [등록증 보기] [PDF 다운로드]
✅ 영업배상책임보험 가입                [보험증권 보기]
```

> 미완: `frontend/public/downloads/credentials/`에 실제 PDF를 넣어야 한다.

### 시공사례에 실적증명 정보 노출

갤러리형 포트폴리오만으로는 부족하다. 발주처·작업규모가 드러나야 한다.

- 기존 표시: 제목, 썸네일, 카테고리, 연도
- 추가 표시: 발주처 유형(`client_type`), 작업 규모(면적/수량), 지역
- 필터에 **발주처 유형** 추가 → 공무원이 "관공서 실적만" 볼 수 있게 (구현됨)

### 견적 프로세스

공무원의 가장 큰 pain point는 **빠른 견적서 확보**. 수의계약은 대개 급하게 진행된다.

`/request` 페이지 2탭 구조:

- **탭 1 — 수목 진단 의뢰**: 이름, 연락처, 이메일, 수목 위치, 증상, 사진 → `POST /diagnosis/`
- **탭 2 — 수의계약 견적 요청**: 소속기관 유형, 기관명, 담당자, 연락처, 이메일,
  작업유형, 작업위치, 희망시기, 예산규모, 상세내용, 참고사진 → `POST /estimate/`
  (`?tab=estimate`로 직접 진입 가능)

핵심 차별점으로 폼에 명시할 것:

- **"견적서 발급: 접수 후 1영업일 이내"**
- **"실적증명서·자격증빙 견적서와 함께 발송"**

## 핵심 메시지

공무원이 사이트에서 **30초 안에** 확인할 수 있어야 하는 것:

1. "이 업체는 자격이 된다" → 1종 나무병원 + 조경업 면허 (증빙 다운로드)
2. "관공서 실적이 있다" → 발주처 로고 + 건수 (감사 대비 근거)
3. "내가 필요한 작업을 한다" → 서비스별 실적 카드
4. "견적을 빨리 받을 수 있다" → "1영업일 이내" + 전화번호
5. "증빙자료를 바로 받는다" → "견적서와 함께 자격증빙·실적증명 발송"
