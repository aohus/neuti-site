# 제품 정의

## 1. 목적

느티나무병원 협동조합을 소개하고 **공사 계약 수주로 연결되는 홈페이지**를 만드는 것.

세부 목표:

- **수주 확대** — 포트폴리오 전시를 통해 공사 계약 수주 유도
- **문의 채널 구축** — 수목 진단 의뢰, 수의계약 견적 요청 창구
- **브랜드 홍보** — "나무는 삶의 동반자" 철학과 전문성으로 신뢰도 제고
- **기록·전시** — 사업 영역과 실적을 체계적으로 아카이빙

원본 콘텐츠 소스는 `assets/` 아래에 있다:

- 홍보 브로슈어: `assets/브로슈어/`
- CEO(권정미) 인터뷰: `assets/content_text/ceo_interview.md`
- 회사 소개: `assets/content_text/회사소개.md`
- 공사 실적: `assets/content_text/공사실적.md`
- 페이지 레퍼런스 이미지: `assets/page_reference/`
- 수목진단 의뢰서 양식: `assets/의뢰서/수목진단의뢰.hwp`

## 2. 타깃 고객

| 우선순위 | 대상 | 특징 |
|---------|------|------|
| **주요** | 지자체 조경·수목 관리 담당 공무원 | 수의계약 발주. 자격증빙·실적증명 필요 |
| 부수 | 사기업 청사 관리자, 아파트 관리사무소 | 정기 조경 관리 계약 |
| 부수 | 개인 정원 소유자 | 수목 진단·치료 단건 |

**의사결정 구조**: 발주 기반 (입찰/견적 → 계약 → 시공)

### 공무원의 선택 기준

공무원은 **"왜 이 업체를 선택했는가"를 감사 시 설명할 수 있어야** 한다.
홈페이지가 그 근거를 제공해야 한다.

```
[필수] 자격 요건 충족    → 1종 나무병원 등록, 조경업 면허
[필수] 견적서            → 예산 범위 확인, 빠른 발급
[필수] 실적증명          → 감사 대비 근거 자료
[가산] 유사 실적         → 비슷한 작업 경험
[가산] 관공서 실적       → 동료 벤치마킹
[가산] 지리적 접근성     → 현장 대응 속도
```

## 3. 고객 여정 (4단계)

방문자가 자연스럽게 답을 얻어야 할 4가지 질문:

1. **"내가 맡길 일을 한 적이 있나?"** → 서비스 카테고리(기술력 섹션)
2. **"작업 품질이 어떤가?"** → 시공사례 before/after, 상세 내용
3. **"신뢰할 만한 회사인가?"** → 정부기관 클라이언트 로고, 실적 수치
4. **"견적은 어떻게?"** → 견적/문의 CTA, 수목진단 의뢰 폼

## 4. 사이트 구조

상단 탭은 클릭 시 페이지를 이동하며, 탭 메뉴는 항상 유지된다.

| 경로 | 페이지 | 설명 |
|------|--------|------|
| `/` | 홈 | 5섹션 구성 (아래 참조) |
| `/about` | 회사소개 | CEO 인터뷰·브로슈어 기반 철학과 방향 |
| `/business` | 주요사업 | 나무병원 / 조경식재 섹션, 카테고리별 시공사례 자동 노출 |
| `/performance` | 시공사례 | 필터: category, year, job_main, site_type, client_type |
| `/performance/[id]` | 시공사례 상세 | 마크다운 렌더링, before/after 이미지 행 |
| `/contract` | 수의계약 안내 | 공무원 전용 랜딩 (SEO 핵심 전환 페이지) |
| `/notice` | 공지사항 | 게시판 CRUD. 관리자만 작성/수정/삭제, 일반은 읽기 |
| `/qna` | 시공/견적문의 | 게시판 CRUD. 누구나 작성, 관리자만 답변. 비밀글 지원 |
| `/request` | 의뢰 폼 | 2탭 — 수목 진단 의뢰 / 수의계약 견적 요청 |
| `/login` | 관리자 로그인 | |
| `/admin/estimates` | 견적 요청 관리 | 상태별(새 요청/처리중/처리완료) 필터·변경·삭제 |

## 6. 디자인 전략

- **Concept**: "생명을 살리는 전문가 & 따뜻한 마을 공동체"
- **Tone & Manner**: 진정성 있는, 전문적인, 따뜻한, 신뢰할 수 있는
- **UI 레퍼런스**: https://www.namoohealthcoop.or.kr/s01/s01.php
- **핵심 요소**: 전략적 랜딩 레이아웃(성과-과정-제안 흐름), 실적 통계, before/after 갤러리,
  타겟별(아파트/공공기관) 진입로, 무한 롤링 발주처 배너, 모바일 최적화

### 비주얼 아이덴티티

- **Theme**: Nature-Friendly & Earthy
- **Primary Colors**: Green (생명, 나무), Brown/Earth (흙, 안정감)
- **Atmosphere**: 자연과의 조화, 심리적 안정감, 전문적인 치유
- **Design Philosophy**: 자연의 편안함과 나무병원의 전문성을 함께 드러내는 깔끔한 레이아웃

### 카피 문체

- 신뢰감을 주기 위해 정중하고 객관적인 어조
- 전문 용어는 정확하게 쓰되, 일반인이 이해하도록 맥락 제공
- "나무는 삶의 동반자" 철학을 바탕으로 진정성 유지
- 시공사례 포스팅은 마케팅 수사 대신 나무의사·조경 실무 용어를 쓰고, 사진과 캡션을 일치시키며,
  마지막은 의뢰 문의로 마무리한다
